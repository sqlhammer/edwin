Using EDWIN in Web Portals

EDWIN works in browser-based AI portals like Claude Projects, Gemini Gems, and Microsoft Copilot. You paste EDWIN's instructions and skills into the portal's custom-instructions box.

What you'll need

  • EDWIN installed locally (see Getting Started)
  • An account with one of the supported portals
  • The Terminal (macOS) or Command Prompt (Windows) — just briefly, to generate the bundle

How long this takes

10 minutes to generate and paste. Refreshing after changes takes 2–3 minutes.

What gets exported

When you export EDWIN for a portal, a script generates a bundle containing:

  • EDWIN's persona — who EDWIN is and how it works
  • Skills for your chosen context — Work, Home, or Global
  • Degradation rewrites — skills are automatically rewritten to work without shell access or OS-level scheduling
  • Personal data (opt-in) — your memory digest and logged accomplishments, if you choose to include them

Privacy note: Only include personal data if you're pasting into your own account. Never share a bundle with personal data.

Generating a bundle

Step 1: Open your terminal

macOS: Open Terminal (search for "Terminal" in Spotlight).

Windows: Open Command Prompt or PowerShell (search for "cmd" or "PowerShell" in the Start menu).

Step 2: Navigate to your EDWIN directory

macOS: Type cd ~/edwin and press Enter.

Windows: Type cd %USERPROFILE%\edwin and press Enter.

Step 3: Run the bundle generator

Type this command, replacing Work with your context and claude with your portal:

node tools/bundle/build-bundle.mjs --context Work --portal claude

Portals: claude, gemini, copilot, or all to generate bundles for all three.

To include personal data: Add --include-memory or --include-brags to the command. Example:

node tools/bundle/build-bundle.mjs --context Work --portal claude --include-memory

Step 4: Find your bundle

The script writes the bundle to:

macOS: ~/edwin/dist/bundles/[portal]/[context]/

Windows: %USERPROFILE%\edwin\dist\bundles\[portal]\[context]\

Inside that folder you'll find:

  • instructions.txt — the main file you'll paste
  • knowledge/ (if supported by the portal) — skill files to upload

Pasting into each portal

Each portal has a slightly different interface. The exact wording of buttons and menus may change, but you're looking for the place where you configure a project or agent with custom instructions.

Claude Projects (claude.ai)

Creating or editing a project

  1. Log in to claude.ai
  2. Find the Projects section in the left sidebar
  3. Create a new project or open an existing one
  4. Look for a section labeled "Custom instructions" or "Project instructions"
  5. Open the instructions.txt file from your bundle folder and copy its entire contents
  6. Paste into the custom instructions box
  7. If there is a "Project knowledge" or "Knowledge" section, upload all the files from the knowledge/ folder
  8. Save the project

Character limit unknown: Claude Projects does not publish a documented character limit. If your paste is rejected, see "What if the bundle is too long" below.

Gemini Gems

Creating or editing a Gem

  1. Log in to Gemini
  2. Look for a section labeled "Gems", "Create a Gem", or similar
  3. Create a new Gem or edit an existing one
  4. Find the instructions box (may be labeled "Custom instructions" or "Instructions")
  5. Open the instructions.txt file from your bundle folder and copy its entire contents
  6. Paste into the instructions box
  7. Save the Gem

Character limit unknown: Gemini does not publish a documented character limit for Gem instructions. If your paste is rejected, see "What if the bundle is too long" below.

Note: Gemini does not support uploading knowledge files as of this writing. All skill instructions are inlined in the instructions.txt file.

Microsoft Copilot

Creating or editing a declarative agent

  1. Log in to Microsoft 365 Copilot
  2. Look for a section labeled "Declarative agents" or "Custom agents"
  3. Create a new agent or edit an existing one
  4. Find the instructions field
  5. Open the instructions.txt file from your bundle folder and copy its entire contents
  6. Paste into the instructions field
  7. Save the agent

Character limit: 8,000 characters. Microsoft Copilot enforces a hard limit of 8,000 characters for declarative agent instructions. If your bundle exceeds this, the generator will automatically create a condensed variant. If the condensed variant still exceeds the limit, you'll see a failure message — see "What if the bundle is too long" below.

Note: Microsoft Copilot does not support uploading knowledge files as of this writing. The condensed variant omits full skill bodies to fit the limit.

What if the bundle is too long?

If the portal rejects your paste as too long:

  1. Check the output folder for a file named CONDENSED_VARIANT.md or FAILURE_MANIFEST.md. These explain what happened.
  2. Try a narrower context. Exporting Global includes all skills. Exporting Work or Home includes fewer.
  3. Remove personal data. If you added --include-memory or --include-brags, regenerate without them.
  4. Use a different portal. Claude Projects and Gemini Gems have unknown or larger limits than Copilot.

Refreshing after changes

When you edit skills or update EDWIN locally, your portal bundles become stale. To regenerate only the changed bundles:

Refresh stale bundles

Run this command in your EDWIN directory:

node tools/bundle/build-bundle.mjs --context Work --portal all --diff

The --diff flag checks which bundles are out of date and regenerates only those. The script then prints re-paste instructions for each portal.

Limitations in web portals

EDWIN works differently in web portals than it does locally in Claude Code or Claude Desktop:

  • No shell access. Skills that invoke scripts are automatically rewritten to use file-based workarounds or to prompt you for manual steps.
  • No OS scheduling. The scheduler skill (recurring tasks, reminders) is unavailable. EDWIN will suggest calendar reminders with prepared prompts instead.
  • Memory and brags are static. If you include personal data, it's a snapshot from when you generated the bundle. EDWIN can't update it in the portal — only locally.
  • No automatic updates. You must regenerate and re-paste bundles manually after updating EDWIN.

When to use portals: Web portals are best for using EDWIN on a machine where you can't install Claude Code or Desktop, or when you want a read-only snapshot of your skills for a specific project.
