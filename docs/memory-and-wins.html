Memory and Wins

What you'll need

  • EDWIN installed and configured
  • A few preferences or facts you'd like EDWIN to remember

How long this takes

5 minutes to understand, ongoing benefit as you use EDWIN.

How EDWIN remembers

EDWIN has a memory system that learns durable facts about you — preferences, people, work patterns, stable information — across sessions. It's like a human assistant who remembers how you like things done.

What EDWIN remembers

EDWIN organizes memory into five categories:

  • Preferences: How you like things done (verbosity, style, tools you use)
  • People: Names, roles, relationships
  • Work patterns: Recurring workflows, schedules, team structures
  • Facts: Stable information like your role, location, contexts, tech stack
  • Dislikes: Things to avoid, never-do rules

What EDWIN won't remember

Privacy rules (never violated):

  • No credentials, API keys, passwords, tokens, secrets
  • No health information, financial details, account numbers
  • No details about third parties unless you explicitly say "remember this about [person]"

How memory works

Observation and confirmation

As you work with EDWIN, it watches for durable signals:

  • Stated preferences ("I prefer X", "always do Y")
  • Corrections to EDWIN's behavior ("Actually, I use Emacs not Vim")
  • Recurring people or projects mentioned by name
  • Stable facts you volunteer (role, tools, team names)

When EDWIN notices something worth remembering, it accumulates candidates. At a natural pause — when a task is complete, not in the middle of work — it asks once, batched:

EDWIN: I noticed a few things worth remembering:

1. Prefers hyper-concise responses

2. Uses VS Code as primary editor

3. Team lead: Jordan

Keep any of these?

You can accept all, pick specific ones, or decline:

You: 1 and 2

EDWIN: Remembered both.

EDWIN asks once. If you decline something, it won't propose that item again. This is called a "tombstone" — EDWIN marks it as rejected and never brings it up.

Explicit memory capture

You can also tell EDWIN to remember something directly:

Say "remember that..."

You: Remember that I prefer snake_case for variables

EDWIN: Remembered: Prefers snake_case for variables

You: Remember this: I report to Jordan

EDWIN: Remembered: Reports to Jordan

Recalling memory

EDWIN recalls memory automatically when it's relevant — you don't need to ask. But if you want to see what's stored:

Ask "what do you remember about me?"

You: What do you remember about me?

EDWIN: Here's what I remember:

Preferences:

- Hyper-concise responses

- Verbosity: concise

- Prefers snake_case for variables

People:

- Reports to: Jordan (manager)

Facts:

- Primary contexts: Work, Home

- Tech stack: Node.js, PostgreSQL

Forgetting

If something is no longer relevant or was captured incorrectly:

Say "forget..."

You: Forget that I report to Jordan

EDWIN: Forgotten: Reports to Jordan

Tidying memory

Over time, memory can accumulate duplicates or stale entries. EDWIN can consolidate:

Say "tidy your memory"

You: Tidy your memory

EDWIN: (Scans for duplicates, checks if old entries are still current, regenerates the memory digest)

Memory tidied. Digest regenerated with 12 entries.

Where memory lives

Your memory is stored in the EDWIN folder at:

  • user/memory/memory.md — all confirmed memories
  • user/memory/digest.md — a shorter version that EDWIN reads in every conversation
  • user/memory/pending.md — candidates waiting for confirmation

These files are plain text. You can open and edit them by hand if you prefer. They never leave your machine — EDWIN doesn't sync them anywhere.

Tracking wins (accomplishments)

EDWIN's brag tracker keeps a running record of your wins — shipped features, positive feedback, milestones, hard conversations — so nothing gets forgotten at performance review time.

Why track wins?

When it's time for a performance review, promotion packet, or year-end reflection, most people struggle to remember what they accomplished six months ago. EDWIN solves this by logging wins as they happen.

How win tracking works

Just like memory, EDWIN watches for accomplishment signals during conversation:

  • You shipped something ("deployed X", "launched Y")
  • You got positive feedback ("client loved it", "manager praised the approach")
  • You hit a milestone ("reached 100K users", "finished the migration")
  • You handled a hard conversation ("gave difficult feedback", "negotiated terms")
  • Personal achievements ("ran a marathon", "published an article")

At a natural pause, EDWIN offers to log them:

EDWIN: I noticed a few wins:

1. Shipped the analytics dashboard — user engagement doubled

2. Manager said the incident response was "textbook"

Log any of these?

You: Both

EDWIN: Logged both under Work.

Explicit logging

You can also log wins directly:

Say "log a win" or "brag: ..."

You: Log a win: finished the Rust course

EDWIN: Win logged under Learning (notable).

You: Brag: negotiated new vendor contract, saved 20%

EDWIN: Win logged under Work (notable).

Win sizes

EDWIN categorizes wins by impact:

  • Small: Routine accomplishment, positive moment (fixed a gnarly bug, helped a colleague)
  • Notable: Significant work, visible impact (shipped a feature, key milestone)
  • Major: High-impact, career-defining (launched a product, promoted, major public win)

EDWIN suggests a size based on how you describe the win. You can adjust it:

You: Change that win to major

EDWIN: Updated to major.

Viewing your wins

Say "show my wins"

You: Show my wins this quarter

EDWIN: Q3 2026 — Work wins (notable and major):

- [Aug 15] Shipped the analytics dashboard — doubled user engagement (major)

- [Jul 22] Led the incident response for the outage — minimal downtime (notable)

- [Jul 10] Negotiated new vendor contract, saved 20% (notable)

You can filter by category, size, or date range:

You: Show major wins only

You: Show my Work wins from last month

Generating a brag document

When it's performance review time, EDWIN can turn your wins into a polished document:

Say "generate my brag doc"

You: Generate my brag doc for Q3

EDWIN: Brag doc generated: user/brags/exports/brag-doc-2026-09-30.md (12 entries, performance-review mode)

EDWIN creates a structured document with your wins grouped by theme, written in impact-framed language suitable for promotion packets or manager 1-on-1s.

There's also a personal-retrospective mode for year-end reflections:

You: Generate a personal retrospective for 2026

EDWIN: (Creates a chronological, celebratory document for personal reflection)

Where wins are stored

Wins live in the EDWIN folder at:

  • user/brags/brags.md — all logged wins
  • user/brags/categories.json — win categories (Work, Learning, Personal, etc.)
  • user/brags/exports/ — generated brag documents

These files are plain text and never leave your machine.

Turning off observation

If you don't want EDWIN watching for memories or wins, you can disable observation:

You: Turn off memory capture

EDWIN: (Sets preferences.memoryCapture to false)

You: Turn off brag detection

EDWIN: (Sets preferences.bragDetection to false)

You can still use explicit commands ("remember that...", "log a win") even when observation is off.

Going off the record

For a single session where you don't want anything remembered:

You: Go off the record

EDWIN: Off the record. Nothing from this session will be remembered.

To resume:

You: Go back on the record

EDWIN: Back on the record.

If something goes wrong

Common issues:

  • EDWIN doesn't offer to remember things: Check if memory capture is enabled: "show my config". If memoryCapture is false, turn it back on.
  • Memory seems stale: Say "tidy your memory" to consolidate and refresh.
  • Can't find my brag doc: It's saved to user/brags/exports/ in the EDWIN folder. The filename includes the date it was generated.
  • Want to edit memory or wins by hand: The files are plain markdown in user/memory/ and user/brags/. You can edit them directly.

For more help, see the Troubleshooting guide.
