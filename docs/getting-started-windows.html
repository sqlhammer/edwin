Getting Started with EDWIN (Windows)

What you'll need

  • Node.js version 18 or later (the installer will help you get this if you don't have it)
  • Git (the installer will help you get this if you don't have it)
  • Claude Code or Claude Desktop (the app you use to talk to Claude)
  • About 50 MB of disk space

How long this takes

10–15 minutes for first-time installation, 5 minutes if you already have Node.js and Git.

Step 1: Download the installer

Download two files, into the same folder

Go to the EDWIN folder (the repository on your computer or on GitHub) and find both of these:

tools\installers\EDWIN-Install.cmd
tools\installers\EDWIN-Install.ps1

Download both into your Downloads folder, or anywhere you can easily find them — but into the same folder. The .cmd is the file you double-click; the .ps1 next to it is the installer itself. If you only take the first one, it will tell you the second is missing rather than doing anything half-finished.

Two files rather than one because Windows won't run a PowerShell script when you double-click it — it opens it in an editor instead. The .cmd exists purely to start the real installer.

Step 2: Run the installer

Double-click EDWIN-Install.cmd

Find the file in your Downloads folder and double-click it to run.

A Command Prompt window will open. This is where you type commands in Windows — don't worry, the installer will guide you through everything.

Follow the installer prompts

The installer will:

  1. Check if you have Node.js and Git installed
  2. If you're missing either one, it will ask "Install Node.js now?" — press Y and it installs it for you. Nothing to download or find in a browser.
  3. Ask where you want to install EDWIN (default: a folder called "edwin" in your user directory)
  4. Download EDWIN and set everything up
  5. Install EDWIN's skills and persona into Claude

The installer will tell you exactly what it's doing as it goes. If something goes wrong, it will tell you how to fix it.

About those permission prompts

If Node.js or Git needs installing, Windows will show a "Do you want to allow this app to make changes to your device?" box. Click Yes. That's Windows asking, not EDWIN — installing software for every user on the machine requires it.

The installer uses winget, the software installer built into Windows 10 and 11, so the download comes from Microsoft's catalogue. On an older or locked-down Windows that doesn't have winget, it downloads Node.js and Git directly from their official sites instead, and checks the Node.js download against the official checksum before installing it.

If it says a tool installed but still can't find it: close the Command Prompt window and double-click the installer again. Windows only gives a program the list of installed tools when it starts, so a fresh window is sometimes needed. The installer tells you when this is the problem.

Step 3: Restart Claude

Quit and reopen Claude

After the installer finishes, you need to restart Claude so it picks up the new skills:

  • Claude Code: Type /quit in the conversation, then open Claude Code again
  • Claude Desktop: Quit the app (Alt+F4 or close all windows) and reopen it

Step 4: Complete first-run setup

Say "set up EDWIN"

Open a new conversation in Claude and type:

You: set up EDWIN

EDWIN: I'm EDWIN — your personal AI assistant. Before we begin properly, I need a few details:

1. What should I call you?

2. How would you like to be addressed?

3. Which contexts do you work in? I can set up Work, Home, or just Global (everything in one place).

4. What's your primary harness? (Claude Code terminal, Claude Desktop, Cowork, or web portal)

5. What OS are you on? (Windows, macOS, Linux)

6. Verbosity preference: concise (brief, offer detail) or detailed (slightly fuller responses)?

Answer the questions. Here's an example:

You: Call me Alex. Work and Home contexts. Claude Code. Windows. Concise.

EDWIN: All set, Alex. I'm ready when you are.

Quick tour:

- I organize my capabilities into skills — focused methodologies for specific tasks. You're currently in the Global context.

- To switch contexts: "Switch to Work" or "Switch to Home".

- To see what I can do: "List skills" or "What skills are in this context?"

- To create a new skill: just describe the task you need help with, and I'll offer to turn it into a skill if I see a pattern.

Step 5: Try it out

Ask EDWIN what it can do

Try these commands to get familiar:

You: List skills

EDWIN: (Shows you all available skills, grouped by context)

You: Switch to Work

EDWIN: Switched to Work.

You: What skills are available?

EDWIN: (Shows skills tagged for Work context, plus Global skills)

What contexts mean

EDWIN organizes skills into three contexts: Global, Work, and Home. Think of contexts like different modes:

  • Global means all skills are equally relevant — no filtering
  • Work prioritizes skills related to professional tasks, but all skills remain available
  • Home prioritizes skills for personal projects and learning, but all skills remain available

Important: Contexts don't restrict what you can do. They just help EDWIN suggest the right skill when you ask something that could match multiple skills. You can always use any skill in any context.

If something goes wrong

Most issues come down to one of these:

  • Skills don't appear after installation: Restart Claude (quit and reopen)
  • Node.js or Git missing: The installer detects this and installs them for you — just press Y when it asks. If it then says it still can't find the tool, close the Command Prompt window and run the installer again.
  • "set up EDWIN" does nothing: EDWIN might already be configured. Try saying "list skills" to see if it's working
  • Permission errors during installation: Right-click the installer and choose "Run as administrator"

For more help, see the Troubleshooting guide.
