Scheduled Tasks

EDWIN can schedule recurring or future-dated tasks — like a morning briefing every weekday, or a Friday reminder. The task runs automatically at the scheduled time, invoking EDWIN with a prepared prompt.

What you'll need

  • EDWIN installed locally via Claude Code or Claude Desktop
  • macOS users: No additional setup
  • Windows users: No additional setup

How long this takes

2 minutes to create a task. Listing and removing tasks takes seconds.

What gets scheduled

When you schedule a task, EDWIN:

  • Saves your exact prompt to a file
  • Creates a job in your operating system's native scheduler (launchd on macOS, Task Scheduler on Windows)
  • Registers the task in user/schedule.json so EDWIN remembers it

At the scheduled time, the OS invokes Claude Code with your prompt. The result is logged to user/schedule-logs/.

Web portals: Scheduled tasks require Claude Code or Claude Desktop. In web portals (claude.ai, Gemini, Copilot), EDWIN will suggest creating a calendar reminder with a prepared prompt instead.

Creating a scheduled task

Just tell EDWIN what you want and when:

You: Brief me every weekday at 8am

EDWIN: Scheduled: **Morning briefing** will run every weekday at 8:00 AM. Logs: user/schedule-logs/edwin-1234567890-morning-brief.log

You: Remind me every Friday at 5pm to review my wins

EDWIN: Scheduled: **Friday win review** will run Fridays at 5:00 PM. Logs: user/schedule-logs/edwin-1234567891-friday-win-review.log

Safety confirmation: EDWIN will confirm the schedule and show you the exact prompt before creating the task. If the prompt contains destructive actions (delete, remove, reset), EDWIN adds an explicit confirmation step to the scheduled prompt itself.

What you can schedule

Examples of tasks that work well:

  • Recurring briefings: "Summarize my calendar every morning at 7"
  • Reminders: "Remind me every Monday at 9 to review the sprint board"
  • Periodic checks: "Every Friday at 4, ask me what I accomplished this week"
  • Future one-offs: "Remind me next Thursday at 2pm to call the contractor"

Tasks that won't work:

  • Anything requiring live data from external systems EDWIN doesn't have access to
  • Multi-step workflows where you need to respond mid-task (use skills instead)

Listing scheduled tasks

You: What have you scheduled for me?

EDWIN: Scheduled tasks (2):
  Morning briefing — Every weekday at 8:00 AM
  Friday win review — Fridays at 5:00 PM

You: List my scheduled tasks

EDWIN: (Shows the same list)

Removing a scheduled task

You: Cancel the morning briefing

EDWIN: Removed: **Morning briefing** is no longer scheduled.

You: Remove the Friday reminder

EDWIN: Removed: **Friday reminder** is no longer scheduled.

EDWIN removes the OS job, deletes the prompt and log files, and updates the registry.

Where tasks are stored

EDWIN stores scheduled task data in three places:

Location What's there
user/schedule.json Registry of all tasks — name, schedule, prompt, log path
user/schedule-prompts/ Prompt files (one per task)
user/schedule-logs/ Output from each scheduled run

The OS-level jobs are stored separately:

  • macOS: ~/Library/LaunchAgents/com.edwin.task.[id].plist
  • Windows: Task Scheduler, under the EDWIN\ folder

Checking task logs

Each scheduled run writes output to its log file in user/schedule-logs/. You can read these files to see what EDWIN generated at each run.

You: Show me the log for the morning briefing

EDWIN: (Reads and displays the log file)

If a task stops running

When you list scheduled tasks, EDWIN checks whether the OS job still exists. If it finds a mismatch, it reports:

EDWIN: Warning: Task "Morning briefing" is in the registry but the OS job is missing. Want me to recreate it or remove the registry entry?

This can happen if:

  • You manually deleted the OS job
  • A system update or permission change broke the job
  • The task file was moved or renamed

EDWIN will offer to fix the mismatch. Choose "recreate" to restore the OS job, or "remove" to clean up the registry entry.

Examples

Daily morning briefing

You: Every weekday at 7am, brief me on my calendar for the day

EDWIN: Confirming schedule:

Every weekday at 7:00 AM
Prompt: "Brief me on my calendar for the day"

You: Confirm

Limitations

  • Requires local installation. Scheduled tasks only work in Claude Code or Claude Desktop, not in web portals.
  • Machine must be awake. The OS scheduler only runs tasks when your machine is powered on and not asleep. If the machine is off at the scheduled time, the task won't run.
  • No multi-step workflows. The scheduled prompt runs once and logs the result. If you need back-and-forth conversation, use a skill interactively instead.
